# Homestay Booking & Reviews

## 1. Problem Statement
Develop a Java-based Homestay Booking & Reviews system that allows hosts to manage homestay listings and guests to book accommodations. The system should support availability checking, booking management, payment recording, cancellation fee calculation, and guest reviews after a completed stay.

## 2. Objectives
- Manage host and guest details.
- Add homestay listings with location and price.
- Create bookings using check-in and check-out dates.
- Check availability and prevent overlapping bookings.
- Record Cash and UPI payments.
- Manage cancellations and calculate cancellation fees.
- Allow guests to submit reviews after completing their stay.

## 3. Technologies Used
- Programming Language: Java
- IDE: Eclipse
- Concepts: Object-Oriented Programming, Inheritance, Abstraction, Encapsulation, ArrayList, and LocalDate.

## 4. Project Structure
- `model` – Person, Host, Guest, Listing, Booking, Review
- `payment` – Payment, CashPayment, UpiPayment
- `service` – HomestayService, Cancellation
- `app` – Main application class

## 5. How to Compile and Run

### Using Eclipse IDE
1. Import or open the project in Eclipse.
2. Ensure all Java files are in their correct packages.
3. Open `Main.java` in the `app` package.
4. Right-click and select **Run As → Java Application**.
5. Follow the instructions displayed in the Console.

### Using the Command Line
Compile and run the project using Eclipse or a configured Java environment. If using the command line, compile all source files with the appropriate module configuration and run the main class using the project's module name and main class.

## 6. Expected Outcome
The application allows users to manage homestay listings, bookings, payment records, cancellations, availability, and reviews through a menu-driven Java console interface.

## 7. Data Storage
This version stores records in memory. Data is reset when the application is restarted.
